### Tecnologías utilizadas:
- Python 3.x  
- OpenCV (cv2)  
- NumPy  
- matplotlib  
- scikit-image  
- watermark

---

### Se trata de:
**Contenido del Notebook**
- Instalación de bibliotecas necesarias en Google Colab.
- Creación de un lienzo negro como base para pruebas.
- Dibujo de figuras geométricas utilizando funciones de OpenCV:
  - `cv2.line()` para líneas rectas.
  - `cv2.rectangle()` para rectángulos vacíos o rellenos.
  - `cv2.circle()` para círculos.
  - `cv2.putText()` para insertar texto sobre imágenes.
- Control de propiedades como color, grosor, posición y fuente.
- Visualización de los resultados con `matplotlib`.

---

### Instrucciones de uso:
1. Asegurate de tener Python 3 instalado.
2. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install opencv-python numpy matplotlib scikit-image watermark
   ```
3. Abrí el notebook con Jupyter Notebook, Deepnote o Google Colab.
4. Ejecutá las celdas para ver cómo se crean y modifican imágenes agregando formas y texto.
