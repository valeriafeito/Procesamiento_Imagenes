### Tecnologías utilizadas:
- Python 3.x  
- PIL (Python Imaging Library)  
- matplotlib  
- OpenCV (cv2)  
- scikit-image  
- watermark

---

### Se trata de:
**Contenido del Notebook**
- Instalación de librerías necesarias en entornos como Google Colab.
- Carga de imágenes con `PIL.Image.open()`.
- Visualización básica de imágenes con `matplotlib`.
- Guardado de imágenes en distintos formatos utilizando Pillow.
- Breve mención a otras bibliotecas complementarias para análisis de imágenes.
- Introducción al flujo básico de procesamiento con imágenes: carga → visualización → guardado.

---

### Instrucciones de uso:
1. Asegurate de tener Python 3 instalado.
2. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install pillow matplotlib opencv-python scikit-image watermark
   ```
3. Abrí el notebook con Jupyter Notebook, Deepnote o Google Colab.
4. Ejecutá las celdas en orden para cargar y visualizar imágenes usando PIL.

**Trabajo de Laboratorio: Introducción a la Manipulación de Imágenes Digitales**
