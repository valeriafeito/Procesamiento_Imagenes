### Tecnologías utilizadas

- Python 3.x
- Gemini 2 (modelo generativo multimodal)
- API de Gemini
- Matplotlib
- NumPy

---

### Se trata de:

**Contenido del Notebook**

- Introducción al uso de modelos generativos multimodales aplicados a la generación de imágenes sintéticas.
- Interacción con el modelo **Gemini 2** para solicitar la generación de imágenes artificiales sobre temáticas espaciales.
- Ejemplos de prompts utilizados para guiar la generación de contenido visual.
- Descarga y visualización de las imágenes generadas.
- Análisis visual de las imágenes obtenidas considerando:
  - Composición general.
  - Detalles visuales.
  - Fotorrealismo vs. estética artificial.
  - Coherencia semántica respecto al prompt original.
- Reflexión sobre las potenciales aplicaciones de los modelos generativos en campos como el arte, la educación y la investigación espacial.

---

### Instrucciones de uso

1. Asegurate de tener Python 3 instalado.
2. Configurá el acceso a la API de Gemini 2 (clave de API necesaria).
3. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install matplotlib numpy
   ```
4. Ejecutá el notebook paso a paso desde Jupyter Notebook, Deepnote o Google Colab.
5. Modificá los prompts y observá los diferentes resultados generados por el modelo.

---

### Este repositorio se usa para:

**Trabajo de Laboratorio: Generación de Imágenes Artificiales y Análisis de Contenido Visual**\
El objetivo es experimentar con el uso de modelos generativos avanzados como Gemini 2 para producir contenido visual a partir de descripciones textuales, evaluando la calidad, coherencia y potencial uso de estas imágenes en contextos educativos y de investigación.
