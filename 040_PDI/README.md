### Tecnologías utilizadas

- Python 3.x
- NumPy
- OpenCV (cv2)
- Matplotlib
- PIL (Pillow)

---

### Se trata de:

**Contenido del Notebook**

- Serie de ejercicios prácticos orientados a afianzar los conocimientos en **procesamiento digital de imágenes**.
- Lectura y visualización de imágenes utilizando `cv2.imread()` y `matplotlib`.
- Conversión de imágenes a escala de grises y a otros espacios de color.
- Aplicación de operaciones de filtrado y suavizado.
- Análisis de histogramas de color y transformaciones de contraste.
- Segmentación simple por umbral.
- Operaciones morfológicas básicas.
- Ejercicios guiados paso a paso para experimentar con diferentes técnicas de procesamiento de imágenes.

---

### Instrucciones de uso

1. Asegurate de tener Python 3 instalado.
2. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install numpy opencv-python matplotlib pillow
   ```
3. Ejecutá el notebook en Jupyter Notebook, Deepnote o Google Colab.
4. Seguí los ejercicios propuestos ejecutando cada celda en orden.
