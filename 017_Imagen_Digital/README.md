### Se trata de:
**Contenido del Notebook**
- Definición conceptual de qué es una imagen digital.
- Representación de imágenes como matrices de números (píxeles).
- Instalación de bibliotecas necesarias en Google Colab.
- Carga y visualización de imágenes con `cv2` y `matplotlib`.
- Exploración de propiedades como dimensiones, tipo de dato, y estructura de canales.
- Aplicación de operaciones básicas: inversión de colores, brillo, contraste, etc.
- Comparación visual de la imagen antes y después de aplicar mejoras.

   ```bash
   pip install opencv-python numpy matplotlib scikit-image watermark
   ```

4. Ejecutá las celdas para ver cómo se representan y transforman imágenes digitales.

### Este repositorio se usa para:
**Trabajo de Laboratorio: Representación y Mejora de Imágenes Digitales**  
El objetivo del notebook es entender qué es una imagen digital, cómo se almacena internamente y cómo podemos aplicar transformaciones simples para mejorarla o modificarla.

---

### Actividades sugeridas:
- Cargar una imagen propia y explorar su estructura.
- Aplicar operaciones como invertir colores, ajustar brillo y contraste.
- Comparar imágenes originales y modificadas visual y numéricamente.
- Explorar la matriz de píxeles con `NumPy` para entender el contenido.
- Probar efectos adicionales como binarización o filtro de desenfoque.
