---

### Tecnologías utilizadas

- Python 3.x
- OpenCV (cv2)
- Google Colab (entorno de ejecución)
- HTML / JavaScript (para la interfaz de captura en el navegador)

---

### Se trata de:

**Contenido del Notebook**

- Ejemplo práctico de captura de imágenes utilizando la **webcam** dentro de un notebook en Google Colab.
- Utilización de código HTML y JavaScript embebido para acceder a la cámara del usuario desde el navegador.
- Captura de la imagen desde la webcam y transferencia directa al entorno de ejecución de Colab.
- Conversión de la imagen capturada a un array NumPy para su posterior procesamiento.
- Visualización de la imagen capturada en tiempo real dentro del notebook.

---

### Instrucciones de uso

1. Abrí el notebook en Google Colab (requisito fundamental, ya que usa su capacidad de integración con navegador).
2. Ejecutá las celdas correspondientes paso a paso.
3. Permití el acceso a la cámara cuando el navegador lo solicite.
4. Capturá la imagen deseada y observá su visualización.
5. La imagen queda disponible como array para ser utilizada en posteriores tareas de procesamiento.

---

### Este repositorio se usa para:

**Trabajo de Laboratorio: Captura Directa de Imágenes desde Colab**\
El objetivo es explorar cómo integrar captura de datos visuales en tiempo real dentro de flujos de procesamiento de imágenes en el entorno de Google Colab, permitiendo ampliar las fuentes de datos sin depender de archivos estáticos.

---

### Actividades sugeridas

- Realizar distintas capturas y aplicar transformaciones de procesamiento digital de imágenes.
- Incorporar filtros, segmentación o detección de objetos sobre las imágenes capturadas.
- Integrar el flujo de captura con modelos previamente entrenados (por ejemplo, clasificadores o segmentadores).
- Analizar los posibles problemas de iluminación, calidad o ruido en la captura directa.
- Probar desde distintos dispositivos para observar variaciones en la calidad de captura según la cámara disponible.
