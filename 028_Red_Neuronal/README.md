**Proyecto:**  
Conversión de Celsius a Fahrenheit utilizando una Red Neuronal Simple

**Fecha:** 16/06/2025

---

### Tecnologías utilizadas:
- Python 3.x  
- TensorFlow / Keras  
- NumPy  
- Matplotlib  

---

### Se trata de:  
**Contenido del Notebook**
- Implementación de una red neuronal básica con una sola capa (`Dense`) usando Keras.
- Conversión de temperaturas de grados Celsius a Fahrenheit como ejemplo introductorio al aprendizaje supervisado.
- Entrenamiento del modelo con pares de datos de entrada/salida.
- Visualización de la función de pérdida durante el proceso de entrenamiento.
- Predicción sobre nuevos valores.
- Comparación con la fórmula matemática real de conversión para validar el comportamiento de la red.
- Impresión de los pesos aprendidos por la red neuronal.

---

### Instrucciones de uso:
1. Asegurate de tener instalado Python 3 y las siguientes librerías:
   ```bash
   pip install tensorflow matplotlib numpy
   ```
2. Abrí el notebook en Jupyter, Deepnote o Google Colab.
3. Ejecutá las celdas en orden para entrenar el modelo y realizar predicciones.
4. Podés modificar el valor de entrada en Celsius para generar nuevas predicciones.

---

### Este repositorio se usa para:  
**Introducción a Redes Neuronales Artificiales (ANN)**  
El objetivo es comprender cómo una red neuronal puede aprender una relación matemática sencilla, explorando el funcionamiento de sus capas, pesos, función de pérdida y el proceso de entrenamiento.
