### Tecnologías utilizadas

- Python 3.x
- Stable Diffusion (modelo generativo)
- API o servicio de acceso al modelo
- Matplotlib
- NumPy

---

### Se trata de:

**Contenido del Notebook**

- Introducción práctica al modelo **Stable Diffusion** para la generación de imágenes artificiales a partir de descripciones textuales (prompts).
- Ejemplos de prompts utilizados para guiar la generación de imágenes.
- Descripción del proceso de generación basado en difusión y denoising.
- Descarga y visualización de las imágenes generadas.
- Comparación visual de resultados y reflexión sobre las capacidades del modelo.
- Discusión sobre las posibilidades y limitaciones actuales de la generación de imágenes por IA.

---

### Instrucciones de uso

1. Asegurate de tener Python 3 instalado.
2. Configurá el acceso al servicio o API de Stable Diffusion (clave de API o cuenta requerida).
3. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install matplotlib numpy
   ```
4. Ejecutá el notebook desde Jupyter Notebook, Deepnote o Google Colab.
5. Modificá los prompts para explorar distintas temáticas y estilos generativos.

---

### Este repositorio se usa para:

**Trabajo de Laboratorio: Modelos Generativos con Difusión**\
El objetivo es experimentar con uno de los modelos generativos más relevantes de la actualidad, observando el impacto de los prompts sobre los resultados visuales y reflexionando sobre su aplicabilidad en contextos educativos, creativos y científicos.
