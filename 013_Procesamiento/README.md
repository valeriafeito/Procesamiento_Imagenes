### Tecnologías utilizadas:
- Python 3.x  
- NumPy  
- matplotlib  
- scikit-image  
- scipy  
- PIL (Python Imaging Library)

---

### Se trata de:
**Contenido del Notebook**
- Instalación e importación de bibliotecas necesarias para el procesamiento de imágenes.
- Lectura de imágenes utilizando `skimage.data` (ej. astronauta).
- Visualización de imágenes en color RGB.
- Análisis de tipo de datos, dimensiones y rango de valores.
- Conversión de color: de RGB a escala de grises, HSV y otros espacios.
- Comparación entre estructuras de color y análisis visual de diferencias.
- Exploración de estructuras de datos asociadas a imágenes digitales.

---

### Instrucciones de uso:
1. Asegurate de tener Python 3 instalado.
2. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install numpy matplotlib scikit-image scipy pillow
   ```
3. Abrí el notebook con Jupyter Notebook, Deepnote o Google Colab.
4. Ejecutá las celdas paso a paso para observar las conversiones y análisis de cada espacio de color.
