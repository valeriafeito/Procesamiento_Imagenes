### Tecnologías utilizadas
- Python 3.x
- Gradio
- PIL (Pillow)

---

### Se trata de:
**Contenido del Notebook**
- Introducción al uso de Gradio para construir interfaces web simples.
- Instalación e importación de librerías necesarias.
- Desarrollo de una función básica de procesamiento de imágenes (conversión a escala de grises).
- Implementación de una interfaz Gradio para cargar y procesar imágenes.
- Ejecución de la aplicación en local, permitiendo al usuario subir una imagen y visualizar el resultado procesado en tiempo real.
- Primer acercamiento al desarrollo de aplicaciones interactivas con Gradio.

---

### Instrucciones de uso
1. Asegurate de tener Python 3 instalado.
2. Instalá las dependencias necesarias ejecutando:
```bash
pip install gradio pillow
```
3. Abrí el notebook con Jupyter Notebook, Deepnote o Google Colab.
4. Ejecutá las celdas para lanzar la interfaz Gradio.
5. Subí una imagen desde la interfaz web y observá el resultado de la conversión a escala de grises.

---

### Este repositorio se usa para:
**Trabajo de Laboratorio: Primeros pasos en Gradio para Procesamiento Digital de Imágenes**
El objetivo es introducir el concepto de interfaces interactivas para usuarios finales aplicadas a tareas simples de procesamiento de imágenes, facilitando la experimentación inicial con Gradio.
