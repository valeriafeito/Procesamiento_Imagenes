### Tecnologías utilizadas

- Python 3.x
- Stable Diffusion (modelo generativo)
- API de acceso al modelo
- Matplotlib
- NumPy
- PIL (Pillow)

---

### Se trata de:

**Contenido del Notebook**

- Profundización en el uso del modelo **Stable Diffusion** para la generación de imágenes a partir de texto (prompt).
- Introducción a configuraciones avanzadas del modelo (steps, guidance scale, tamaño de imagen).
- Ajuste de los prompts para explorar variaciones estéticas y conceptuales.
- Descarga y visualización de los resultados generados.
- Comparación de imágenes producidas con diferentes parámetros.
- Reflexión sobre el control y la manipulación de la creatividad algorítmica.

---

### Instrucciones de uso

1. Asegurate de tener Python 3 instalado.
2. Configurá el acceso a la API de Stable Diffusion (requiere clave de API y servicio asociado).
3. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install matplotlib numpy pillow
   ```
4. Ejecutá el notebook en Jupyter Notebook, Deepnote o Google Colab.
5. Modificá los prompts y configuraciones avanzadas para observar los distintos resultados.

---

### Este repositorio se usa para:

**Trabajo de Laboratorio: Control de Generación en Modelos de Difusión**\
El objetivo es avanzar en el dominio del proceso de generación de imágenes por IA, comprendiendo cómo los parámetros de configuración impactan en el resultado visual y explorando los límites de control creativo que estos modelos ofrecen.

---

### Actividades sugeridas

- Comparar resultados usando distintas cantidades de pasos de difusión (steps).
- Modificar el guidance scale para observar el grado de fidelidad al prompt.
- Probar distintos tamaños de generación de imagen.
- Analizar el impacto de prompts muy detallados versus prompts genéricos.
- Debatir los aspectos éticos y de propiedad intelectual asociados al uso de estas herramientas.
