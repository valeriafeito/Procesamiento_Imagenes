### Se trata de:
**Contenido del Notebook**
- Actividad integradora con una duración estimada de 1 hora.
- Descarga de una imagen desde URL o carga de imágenes propias.
- Aplicación de técnicas combinadas para:
  - Lectura y visualización de imágenes.
  - Mejora de calidad visual (luminosidad, contraste).
  - Conversión de espacios de color.
  - Segmentación de objetos en la imagen.
  - Presentación visual clara del antes y después.
- Consolidación de conocimientos adquiridos a lo largo de los trabajos anteriores.

### Instrucciones de uso:
1. Asegurate de tener Python 3 instalado.
2. Instalá las dependencias necesarias ejecutando:
   ```bash
   pip install opencv-python numpy matplotlib scikit-image watermark
   ```
3. Abrí el notebook con Jupyter Notebook, Deepnote o Google Colab.
4. Seguí las instrucciones paso a paso para completar el proyecto integrador.
